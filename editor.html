⌨ WIRE EDITOR — INSTRUCTIONS

DRAWING
Click terminal dotStart a new wire
Click empty spaceAdd a waypoint (corner)
Click terminal / dbl-clickFinish the wire
EscCancel wire in progress
EDITING
Click near a wireSelect it
Click a point on selected wireSelect that point (yellow ring)
Arrow keys (point selected)Nudge point by step amount
Click on selected wireInsert a bend point there
Drag any point (● or □)Move it; release near terminal to snap
Right-click a bend pointDelete that node (not the wire)
Delete / BackspaceDelete selected wire
COMPONENTS
Click component bodySelect it (yellow highlight)
Ctrl+ClickAdd / remove from multi-selection
Arrow keysMove selected component(s) by step amount
RRotate selected component(s) 90° CW
Drag component bodyMove it; attached wire ends follow
VIEW
Scroll wheelZoom in / out
Middle-mouse or Alt+dragPan
Double-click empty spaceReset view

HOW TO USE

Start wire: click any terminal dot
Add waypoint: click empty space
Finish wire: click terminal or dbl-click
Cancel: Esc
Select wire: click near it
Add bend: click on selected wire
Move bend: drag the cyan □ handle
Delete bend: right-click cyan □
Delete wire: select → Delete key
Pan: middle-mouse or Alt+drag
Zoom: scroll wheel
